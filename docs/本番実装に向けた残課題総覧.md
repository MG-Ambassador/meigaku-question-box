### 2. R14：実機・スクリーンリーダー・実環境での受入テスト（G-1）
1. **スマートフォン実機表示・操作検証（iPhone Safari / Android Chrome）**：
   - ソフトキーボード展開時に3ステップの入力欄や操作ボタンが隠れず操作可能であること。
   - iOS の safe area（画面下部ホームバー）と固定ナビゲーション・シートが干渉しないこと。
   - OS標準の共有シート（`navigator.share`）から LINE / Instagram 等へ募集リンクを共有できること。
2. **Instagram アプリ内ブラウザ（WebView）検証**：
   - Instagram リンク（`/?room=<id>&from=instagram`）から開いた際、質問投稿・下書き保存・流入元集計（Instagram カウント）が正常に動作すること。
3. **スクリーンリーダー実機検証（iOS VoiceOver / Android TalkBack）**：
   - 視覚情報を見ずに「テーマ選択 → 質問入力 → 確認 → 送信完了」を完遂できること。
4. **本番デプロイ後のスモークテスト実行**：
   ```bash
   npm run smoke:production -- https://mg-ambassador.github.io/meigaku-question-box/ https://<cloud-run-url>
   ```
